# Design references

Historical and visual design material for Open Media Disc (OMD), kept for
reference. This is raw input and archival design work, not normative
documentation: the normative format lives in [`../spec/`](../spec), and the user-
and developer-facing docs live in [`../documentation/`](../documentation).

Contents:

- `images/` product and UI mockups, including `example4_touchScreenUi.png` (the
  touch hub direction that guided the Studio redesign).
- `ThemeExamples/` standalone theme showcases (Frutiger Aero, DORFic, Technozen,
  Dark Aero) as self-contained HTML + CSS + images.
- `OAC_*.md` early design specs and product-family docs from the project's
  Optical Album Cartridge (OAC) era, kept for historical context. Use OMD in new
  work.
